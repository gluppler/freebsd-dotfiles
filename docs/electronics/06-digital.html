Logic levels and noise margins

A digital signal is a voltage read as 1 above one threshold and 0 below another. Outputs promise to stay further out than inputs need, and the gap, the noise margin, is how much noise a signal can pick up on the way and still be read correctly.

Mixing families needs care. A 3.3 V output, at best 3.3 V, is not a guaranteed 1 for a 5 V 74HC input that needs 3.5 V; a 74HCT part, made with TTL input levels, or a level shifter fixes it. A 5 V output into a 3.3 V input can destroy it unless the input is marked 5 V tolerant.

Boolean algebra

Logic has its own algebra, with AND as multiplication, OR as addition and a bar for NOT. Most rules look like ordinary algebra; a few do not, such as A+A=A.

A+0=AA⋅1=AA+A=1A⋅A=0
A+AB=AA+AB=A+BA(B+C)=AB+AC

De Morgan's laws turn an AND into an OR and back by inverting everything:

A⋅B=A+BA+B=A⋅B

So NAND alone can build every other function, and so can NOR. Chips are built mostly from these, since in CMOS they take the fewest transistors.

Karnaugh maps

To simplify a function of up to four inputs, lay its truth table out as a grid whose rows and columns count in Gray code, 00, 01, 11, 10, so that neighbouring cells differ in one input. Then circle rectangles of 1s, each 1, 2, 4 or 8 cells, as large as possible; the edges wrap round. Each rectangle is one AND term, keeping only the inputs that do not change inside it.

Binary arithmetic

An n-bit number holds 2n values. Signed numbers use two's complement: the top bit counts as −2n−1, so the same adder handles positive and negative numbers. To negate, invert every bit and add 1.

A full adder adds two bits and a carry in, giving a sum bit and a carry out:

S=A⊕B⊕CinCout=AB+Cin(A⊕B)

Chained, the carry out of each bit feeds the next. The answer is only right once the carry has rippled all the way through, so an n-bit ripple adder takes n carry delays; faster adders look ahead to compute the carries in parallel.

Multiplexers and decoders

A multiplexer is a switch made of gates: its select input chooses which data input reaches the output. A decoder does the opposite, turning an n-bit number into one of 2n lines, such as a chip select.

Y=SD0+SD1

Latches and flip-flops

Feed two gates' outputs back into each other and the circuit remembers. This SR latch is set by a pulse on S and reset by a pulse on R; with both low it holds. Both high at once is forbidden: it forces both outputs to 0, and the state after they are released is unpredictable.

SRQMeaning
00unchangedhold
101set
010reset
11forbiddenboth outputs 0

A D flip-flop copies its D input to Q only at the rising edge of its clock and holds it between edges. D must be steady from the setup time tsu before the edge until the hold time th after it; Q follows a clock-to-output delay tcq later.

Between two flip-flops, the logic in between must settle within one clock period, which sets the fastest clock; and it must not settle so fast that it upsets the hold time of the next flip-flop:

fmax=1tcq+tpd+tsutcq+tpd,min≥th

A signal from outside, such as a button, is not in step with the clock. Pass it through two flip-flops in a row, a synchroniser, before using it.

Counters and shift registers

Flip-flops that each toggle when the one before falls make a binary counter. Each output runs at half the frequency of the one before, so a counter is also a frequency divider:

fQk=fclk2k+1

Flip-flops in a chain, each D fed from the Q before, make a shift register: at each clock edge every bit moves one place along. The 74HC595 takes bits in one at a time and presents them on eight outputs, so three pins can drive eight LEDs, or many more with chips chained.

State machines

A circuit or program whose behaviour depends on what happened before is a state machine: a set of states, and rules for moving between them on inputs or time. Draw it as a diagram first; the code follows directly. In a Moore machine the outputs depend only on the state, in a Mealy machine on the state and the inputs.

On a microcontroller the same machine is a table and a function called from the main loop, without blocking delays, so the program can do other work meanwhile:

enum state { GREEN, YELLOW, RED };

struct step { enum state next; unsigned long ms; };

static const struct step table[] = {
    [GREEN]  = { YELLOW, 30000 },
    [YELLOW] = { RED,     4000 },
    [RED]    = { GREEN,  30000 },
};

static enum state now = GREEN;
static unsigned long since;

/* Called often from the main loop with a millisecond clock. */
void tick(unsigned long ms)
{
    if (ms - since >= table[now].ms) {    /* unsigned: survives wrap-around */
        now = table[now].next;
        since = ms;
        show(now);
    }
}

With n flip-flops a hardware state machine has up to 2n states. Debouncing a button, decoding a protocol and sequencing a power-up are all state machines.
